# 바탕화면 상어

바탕화면에 상어가 한 마리 산다. 평소에는 숨어 있다가 가끔 검은 실루엣으로 스쳐
지나가고, 밥이 떨어지면 달려와 먹는다. 많이 먹일수록 커지고 또렷해진다.

**밥은 그냥 일하면 준다.**

| 하던 일 | 떨어지는 것 |
|---|---|
| 어디든 클릭 | 그 자리에 **큰 밥** |
| 타자 | 아무 데나 **작은 밥** |

클릭도 키도 **가로채지 않는다.** 누르던 버튼은 그대로 눌리고 치던 글자는 그대로 찍힌다 —
상어는 그 옆에서 주워 먹을 뿐이다. 그래서 켜 두고 하루를 보내는 앱이다.

## 쓰는 법

| 키 | 하는 일 |
|---|---|
| `⌥⇧S` | **밥 주기 멈추기 / 다시.** 남이 화면을 볼 때 끈다 |
| `⌥⇧R` | 랭킹·계정 |
| `⌥⇧H` | 숨기기 / 보이기 |

윈도우는 `Alt+Shift+` 로 같다. 앱을 띄우면 **밥 주기는 늘 켜진 채로** 시작한다.

**맥은 처음 한 번 「손쉬운 사용」 권한을 줘야 타자가 밥이 된다.** 키를 엿듣기만 하고
가로채지 않으며, 어떤 키를 눌렀는지는 게임에 전달되지 않는다 — 몇 번 쳤는지만 센다.
권한을 안 주면 클릭만 밥이 된다.

## 상어 키우기

밥을 먹은 **누적 개수**로 자란다. 여섯 단계다.

| 단계 | 먹은 개수 | |
|---|---|---|
| 1 | 0 | 아기상어 — 아주 흐릿하고 지느러미 둘 |
| 2 | 5 | 가슴지느러미 |
| 3 | 15 | 제2등지느러미 |
| 4 | 35 | 아가미 |
| 5 | 70 | 이빨 |
| 6 | 120 | 흉터 — 다 컸다 |

단계가 오를수록 **더 크고 더 또렷해진다.** 한 번 오른 단계는 내려가지 않는다.

큰 밥은 3, 작은 밥은 1 이다. 클릭은 일부러 하는 것이고 타자는 무심코 하는 것이라
값이 다르다. 타자는 0.6 초에 하나까지만 떨어진다 — 연타로 화면을 채우지 않는다.

오래 굶기면(여섯 시간) 화면을 맴돌며 보챈다. **앱을 꺼 둔 시간도 흐른다** — 하루 만에
켜면 배고파 있다.

## 랭킹

`⌥⇧R` 에서 별명을 정하면 랭킹에 오른다. **몰래 야구와 같은 계정**이라, 야구에서 쓰던
복구 코드를 넣으면 같은 이름으로 붙는다. 계정이 없어도 게임은 전부 된다.

## 만들기

```bash
npm start          # 빌드 → 실행 (맥)
npm test
npm run build:mac
npm run build:win
```

맥은 Swift + WKWebView, 윈도우는 .NET + WebView2. 크로미움을 담지 않아 앱이 0.4MB 다.
