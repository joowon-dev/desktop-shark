# 바탕화면 상어

바탕화면에 상어가 한 마리 산다. 평소에는 흐릿하게 어슬렁거리다가, 밥이 떨어지면
달려와 먹는다. 많이 먹일수록 커지고 또렷해진다. **사라지지는 않는다** — 제일 흐릴
때도 화면 어딘가에 있다.

**밥은 그냥 일하면 준다.**

| 하던 일 | 떨어지는 것 |
|---|---|
| 어디든 클릭 | 그 자리에 **큰 밥** |
| 타자 | 아무 데나 **작은 밥** |

클릭도 키도 **가로채지 않는다.** 누르던 버튼은 그대로 눌리고 치던 글자는 그대로 찍힌다 —
상어는 그 옆에서 주워 먹을 뿐이다. 그래서 켜 두고 하루를 보내는 앱이다.

## 쓰는 법

| 키 | 하는 일 |
|---|---|
| `⌥⇧S` | **밥 주기 멈추기 / 다시.** 남이 화면을 볼 때 끈다 |
| `⌥⇧R` | 랭킹·계정 |
| `⌥⇧H` | 숨기기 / 보이기 |

윈도우는 `Alt+Shift+` 로 같다. 앱을 띄우면 **밥 주기는 늘 켜진 채로** 시작한다.

**권한은 하나도 필요 없다.** 키를 읽는 것이 아니라 **몇 번 눌렀는지만 세기** 때문이다 —
어떤 키였는지는 앱이 알 수가 없다.

## 상어 키우기

밥을 먹은 **누적 점수**로 자란다. 여섯 단계다.

| 단계 | 누적 점수 | |
|---|---|---|
| 1 | 0 | 아기상어 — 아주 흐릿하고 지느러미 둘 |
| 2 | 30 | 가슴지느러미 |
| 3 | 100 | 제2등지느러미 |
| 4 | 250 | 아가미 |
| 5 | 550 | 이빨 |
| 6 | 1000 | 흉터 — 다 컸다 |

단계가 오를수록 **눈에 띄게 커지고 또렷해진다** — 한 단계마다 1.4~1.6 배씩, 1단계에서
6단계까지 **일곱 배 가까이** 자란다. 한 번 오른 단계는 내려가지 않는다.

**큰 밥은 10점, 작은 밥은 1점.** 클릭은 일부러 하는 것이고 타자는 무심코 하는 것이라
열 배 차이다 — 타자는 조금씩 쌓이는 배경이고, 클릭이 먹이는 행위다. 타자는 0.6 초에
하나까지만 떨어지고, 밥은 둘 다 일부러 작게 그린다.

오래 굶기면(여섯 시간) 화면을 맴돌며 보챈다. **앱을 꺼 둔 시간도 흐른다** — 하루 만에
켜면 배고파 있다.

## 도감

상어는 여섯 종이다 — 백상아리 · 뱀상어 · 귀상어 · 환도상어 · 톱상어 · 고래상어.
종마다 실루엣도 크기도 헤엄 속도도 다르다.

지금 키우는 상어를 **6단계까지 키우면 도감에 오른다.** 그다음 `⌥⇧R` 의 도감 탭에서
놓아주면 **아직 못 만난 종**의 아기상어가 온다. 여섯을 다 모으는 것이 이 게임의 끝이다.

## 랭킹

**첫 밥을 주는 순간 `상어0000` 꼴로 이름이 만들어져 랭킹에 오른다.** 마음에 안 들면
`⌥⇧R` 에서 바꾸면 된다 — 바꿔도 같은 계정이다.

랭킹 한 줄에는 **등수 · 이름 · 그 사람의 상어 · 계급 · 점수**가 나온다. 남이 어떤 종을
어디까지 키웠는지 실루엣으로 바로 보인다.

**몰래 야구와 같은 계정**이라, 야구에서 쓰던 복구 코드를 넣으면 같은 이름으로 붙는다.

랭킹이 싫으면 패널의 **「랭킹에 올리기」를 끄면** 아무것도 서버로 안 간다. 상어는
그대로 자란다.

패널은 **제목줄을 잡고 끌어서 옮기고**, 오른쪽 위 **×** 로 닫는다. 띄워 둔 채로도 다른
창을 누르고 타자를 칠 수 있다 — 패널 네모 위에 있을 때만 클릭을 받는다.

## 만들기

```bash
npm start          # 빌드 → 실행 (맥)
npm test
npm run build:mac
npm run build:win
```

맥은 Swift + WKWebView, 윈도우는 .NET + WebView2. 크로미움을 담지 않아 앱이 0.4MB 다.
