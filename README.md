# 바탕화면 상어

바탕화면에 상어가 한 마리 산다. 평소에는 숨어 있다가 가끔 검은 실루엣으로 스쳐
지나가고, 밥을 주면 달려와 먹는다. 많이 먹일수록 커지고 또렷해진다.

마우스는 전부 밑의 앱으로 통과하므로 하던 일을 계속할 수 있다. **밥을 줄 때만**
`⌥⇧S` 로 게임모드를 켠다.

## 쓰는 법

| 키 | 하는 일 |
|---|---|
| `⌥⇧S` | 게임모드 — 켜면 **화면 아무 데나 클릭**해서 밥을 준다 |
| `⌥⇧R` | 랭킹·계정 |
| `⌥⇧H` | 숨기기 / 보이기 |

윈도우는 `Alt+Shift+` 로 같다. 게임모드가 켜져 있는 동안은 밑의 앱을 클릭할 수 없다 —
메뉴바 아이콘이 🐟 로 바뀌고 화면 가장자리에 물빛 테두리가 돈다.

## 상어 키우기

밥을 먹은 **누적 개수**로 자란다. 여섯 단계다.

| 단계 | 먹은 개수 | |
|---|---|---|
| 1 | 0 | 아기상어 — 아주 흐릿하고 지느러미 둘 |
| 2 | 5 | 가슴지느러미 |
| 3 | 15 | 제2등지느러미 |
| 4 | 35 | 아가미 |
| 5 | 70 | 이빨 |
| 6 | 120 | 흉터 — 다 컸다 |

단계가 오를수록 **더 크고 더 또렷해진다.** 한 번 오른 단계는 내려가지 않는다.

오래 굶기면(여섯 시간) 화면을 맴돌며 보챈다. **앱을 꺼 둔 시간도 흐른다** — 하루 만에
켜면 배고파 있다.

## 랭킹

`⌥⇧R` 에서 별명을 정하면 랭킹에 오른다. **몰래 야구와 같은 계정**이라, 야구에서 쓰던
복구 코드를 넣으면 같은 이름으로 붙는다. 계정이 없어도 게임은 전부 된다.

## 만들기

```bash
npm start          # 빌드 → 실행 (맥)
npm test
npm run build:mac
npm run build:win
```

맥은 Swift + WKWebView, 윈도우는 .NET + WebView2. 크로미움을 담지 않아 앱이 0.4MB 다.
