# 바탕화면 상어

바탕화면에 상어가 한 마리 산다. 평소에는 흐릿하게 어슬렁거리다가, 밥이 떨어지면
달려와 먹는다. 많이 먹일수록 커지고 또렷해진다. **사라지지는 않는다** — 제일 흐릴
때도 화면 어딘가에 있다.

**밥은 그냥 일하면 준다.**

| 하던 일 | 떨어지는 것 |
|---|---|
| 어디든 클릭 | 그 자리에 **큰 밥** |
| 타자 | 아무 데나 **작은 밥** |

클릭도 키도 **가로채지 않는다.** 누르던 버튼은 그대로 눌리고 치던 글자는 그대로 찍힌다 —
상어는 그 옆에서 주워 먹을 뿐이다. 그래서 켜 두고 하루를 보내는 앱이다.

## 쓰는 법

| 키 | 하는 일 |
|---|---|
| `⌥⇧S` | **밥 주기 멈추기 / 다시.** 남이 화면을 볼 때 끈다 |
| `⌥⇧R` | 랭킹·계정 |
| `⌥⇧H` | 숨기기 / 보이기 |

윈도우는 `Alt+Shift+` 로 같다. 앱을 띄우면 **밥 주기는 늘 켜진 채로** 시작한다.

**권한은 하나도 필요 없다.** 키를 읽는 것이 아니라 **몇 번 눌렀는지만 세기** 때문이다 —
어떤 키였는지는 앱이 알 수가 없다.

## 상어 키우기

밥을 먹은 **점수**로 자란다. 한 종을 여섯 단계까지 키우는 데 18,000점 —
보통 일하는 리듬으로 **하루**다.

| 단계 | 그 종을 키운 점수 |
|---|---|
| 1 | 0 — 아기상어 |
| 2 | 700 |
| 3 | 2,200 |
| 4 | 5,500 |
| 5 | 10,500 |
| 6 | 18,000 — 다 컸다 |

단계가 오를수록 **눈에 띄게 커지고 또렷해진다** — 1단계에서 6단계까지 일곱 배 가까이.

오래 굶기면(여섯 시간) 화면을 맴돌며 보챈다. **앱을 꺼 둔 시간도 흐른다.**

## 도감 — 여섯 종

백상아리 · 뱀상어 · 귀상어 · 환도상어 · 톱상어 · 고래상어. 종마다 실루엣도 크기도
헤엄 속도도 다르다.

**앞 종을 다 키워야 다음 종이 열린다.** 백상아리를 6단계까지 키우고 점수가 모이면
뱀상어가, 뱀상어를 다 키우면 귀상어가 — 이렇게 차례로 열린다. 건너뛰기는 없다.
여섯 종을 다 모으는 데 **한 주 남짓**.

무엇이 모자란지는 도감이 알려 준다 — 「백상아리를 6,000점 더 키우면 뱀상어가 열립니다」.

`⌥⇧R` 의 도감에서:

- **종을 눌러 데려온다.** 이미 키운 종으로 언제든 돌아갈 수 있다 — 그 종을 키운
  만큼의 모습으로 나온다.
- **「이 모습으로 고정」** — 지금 상어가 더 안 자란다. 마음에 드는 모습에서 멈춰 둘
  수 있고, 그동안에도 다음 종은 계속 열린다.
- **단계 고르기** — 지나온 단계로 되돌려 볼 수 있다. 안 키운 단계는 못 본다.

## 랭킹

**첫 밥을 주는 순간 `상어0000` 꼴로 이름이 만들어져 랭킹에 오른다.** 마음에 안 들면
`⌥⇧R` 에서 바꾸면 된다 — 바꿔도 같은 계정이다.

랭킹 한 줄에는 **등수 · 이름 · 그 사람의 상어 · 계급 · 점수**가 나온다. 남이 어떤 종을
어디까지 키웠는지 실루엣으로 바로 보인다.

**몰래 야구와 같은 계정**이라, 야구에서 쓰던 복구 코드를 넣으면 같은 이름으로 붙는다.

랭킹이 싫으면 패널의 **「랭킹에 올리기」를 끄면** 아무것도 서버로 안 간다. 상어는
그대로 자란다.

패널은 **제목줄을 잡고 끌어서 옮기고**, 오른쪽 위 **×** 로 닫는다. 띄워 둔 채로도 다른
창을 누르고 타자를 칠 수 있다 — 패널 네모 위에 있을 때만 클릭을 받는다.

## 만들기

```bash
npm start          # 빌드 → 실행 (맥)
npm test
npm run build:mac
npm run build:win
```

맥은 Swift + WKWebView, 윈도우는 .NET + WebView2. 크로미움을 담지 않아 앱이 0.4MB 다.
